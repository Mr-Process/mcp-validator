# Security Policy

## Reporting Vulnerabilities

If you discover a security vulnerability within MCP Validator or its fuzzing engine, please report it responsibly by opening a private security advisory or emailing the maintainers directly.

Please do not report security vulnerabilities through public GitHub issues.

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |
